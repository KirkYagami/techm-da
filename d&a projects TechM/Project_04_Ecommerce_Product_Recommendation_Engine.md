### **Project 04**  
**Project Title**: E-commerce Product Recommendation Engine  
**Project Description**:  
Implemented a collaborative filtering-based recommendation system that processes user interaction data through orchestrated pipelines and generates personalized product suggestions using BigQuery ML on Google Cloud.  

**Objective**:  
- Develop Airflow workflows for processing user behavior and product data  
- Train recommendation models using BigQuery ML matrix factorization  
- Implement batch inference for generating recommendations  
- Create dashboards to analyze recommendation performance metrics  
- Support A/B testing framework for model evaluation  
- Ensure scalability for growing catalog and user base  

**Dataset**:  
MovieLens (ml-latest-small) — 100,836 ratings across 9,742 movies from 610 users, maintained directly by GroupLens Research (University of Minnesota). Free, no account required.  
Link: https://grouplens.org/datasets/movielens/latest/ (or mirrored at https://www.kaggle.com/datasets/shubhammehta21/movie-lens-small-latest-dataset)

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on recommendation systems  
**Outcome**:  
Built a complete recommendation pipeline delivering personalized suggestions with supporting analytics, showcasing practical ML application in e-commerce.
