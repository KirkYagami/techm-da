### **Project 06**  
**Project Title**: Customer Feedback Sentiment Analysis Platform  
**Project Description**:  
Built a system to process and analyze large volumes of customer feedback using automated pipelines and ML models to extract sentiment trends and insights.  

**Objective**:  
- Implement Airflow pipelines for ingesting and preprocessing review data  
- Apply BigQuery ML for sentiment classification and topic modeling  
- Aggregate insights across products, regions, and time periods  
- Develop interactive dashboards for sentiment monitoring  
- Schedule regular analysis and reporting jobs  
- Support export of processed insights  

**Dataset**:  
Amazon Fine Food Reviews — ~568,000 reviews with star ratings and free-text review content, spanning 1999–2012. Free, no application required.  
Link: https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on NLP and text analytics  
**Outcome**:  
Created an automated sentiment analysis platform providing valuable customer insights through reliable pipelines and visualizations.
