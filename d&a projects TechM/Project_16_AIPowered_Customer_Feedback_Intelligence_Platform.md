### **Project 16**  
**Project Title**: AI-Powered Customer Feedback Intelligence Platform  
**Project Description**:  
Enhanced the sentiment analysis system with Snowflake storage, advanced Looker BI reporting, and Agentic AI agents that automatically generate response strategies and trend reports.  

**Objective**:  
- Build scalable feedback processing pipelines into Snowflake via Airflow  
- Perform multi-dimensional text analysis using BigQuery ML  
- Develop rich Looker BI dashboards for voice-of-customer insights  
- Implement Agentic AI for automated insight summarization and action recommendations  
- Enable real-time trend detection and alerting  
- Support integration with CRM systems  

**Dataset**:  
Amazon Fine Food Reviews — ~568,000 reviews with star ratings and free-text review content, spanning 1999–2012. Same dataset as Project 06; this version stores it in Snowflake and adds Looker BI dashboards plus an agent that summarizes trends and drafts response strategies. Free, no application required.  
Link: https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud & Data Warehouse**: GCP, Snowflake  
- **ML Modeling**: BigQuery ML  
- **BI & Visualization**: Looker BI  
- **Agentic AI**: Feedback analysis and response agents  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Advanced Data Engineering, ML & Agentic AI project focusing on NLP and customer experience  
**Outcome**:  
Built a comprehensive customer intelligence platform with automated insights and AI-driven actions.
