### **Project 08**  
**Project Title**: Marketing Campaign Performance Analytics  
**Project Description**:  
Designed a comprehensive pipeline to measure and optimize marketing campaign effectiveness through automated data processing and attribution modeling.  

**Objective**:  
- Orchestrate multi-channel data integration using Airflow  
- Build attribution and ROI models with BigQuery ML  
- Develop campaign performance dashboards  
- Automate performance reporting workflows  
- Support incremental data processing  
- Enable A/B test analysis  

**Dataset**:  
Marketing Campaign Dataset (Jack Daoud / Maven Marketing) — 2,240 customers with channel response data (web, catalog, store purchases) and campaign acceptance across 5 historical campaigns. Free, no application required.  
Link: https://www.kaggle.com/datasets/rodsaldanha/arketing-campaign

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on marketing analytics  
**Outcome**:  
Implemented a robust campaign analytics system delivering clear ROI insights and optimization recommendations.
