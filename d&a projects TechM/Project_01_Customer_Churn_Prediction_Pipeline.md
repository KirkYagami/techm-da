### **Project 01**  
**Project Title**: Customer Churn Prediction Pipeline  
**Project Description**:  
Built an end-to-end batch data pipeline for predicting customer churn using historical transaction and behavioral data. The system leverages cloud orchestration for scheduled ETL jobs, trains predictive models directly in the data warehouse, and delivers actionable insights through interactive visualizations, demonstrating strong data engineering and machine learning capabilities on Google Cloud Platform.  

**Objective**:  
- Design and implement a scalable ETL pipeline using Apache Airflow on GCP  
- Perform data ingestion, cleaning, and feature engineering from multiple sources  
- Train and evaluate churn prediction models using BigQuery ML  
- Create interactive dashboards for visualizing churn patterns and key metrics  
- Schedule automated model retraining and prediction jobs  
- Ensure data quality checks and logging throughout the pipeline  
- Document the architecture and deployment process for reproducibility  

**Dataset**:  
Telco Customer Churn (IBM/Kaggle) — 7,043 customers, includes demographics, account info, services signed up for, and churn label. Free, no application required.  
Link: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), Cloud Storage, BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio / Data Visualization tools  
- **Languages & Utilities**: SQL, Python, Bash  

**Project Type**: Intermediate Data Engineering & ML project focusing on batch processing, cloud orchestration, and predictive analytics  
**Outcome**:  
Delivered a fully functional, production-grade customer churn prediction system with automated pipelines, reliable ML models, and insightful visualizations. The project showcases proficiency in modern cloud data stack and serves as a solid foundation for advanced analytics solutions.
