### **Project 11**  
**Project Title**: Advanced Customer Churn Prediction & Retention Intelligence Platform  
**Project Description**:  
Developed an enhanced end-to-end customer churn prediction and retention system that combines cloud orchestration, multi-cloud data warehousing, enterprise-grade BI dashboards, and Agentic AI to deliver automated insights and personalized retention recommendations.  

**Objective**:  
- Orchestrate complex ETL/ELT pipelines using Apache Airflow across GCP and Snowflake  
- Perform advanced feature engineering and model training with BigQuery ML and Snowflake  
- Build interactive enterprise dashboards using Looker BI for churn analysis and segmentation  
- Implement Agentic AI agents for automated root-cause analysis and retention strategy suggestions  
- Enable real-time prediction scoring and automated campaign triggering  
- Ensure data governance, lineage tracking, and cross-platform integration  
- Document the full architecture including AI agent workflows  

**Dataset**:  
Telco Customer Churn (IBM/Kaggle) — 7,043 customers, includes demographics, account info, services signed up for, and churn label. Free, no application required. Same dataset as Project 01; this version layers Snowflake ingestion, Looker BI dashboards, and an LLM agent on top of the same data.  
Link: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud & Data Warehouse**: Google Cloud Platform (GCP), Snowflake  
- **ML Modeling**: BigQuery ML  
- **BI & Visualization**: Looker BI  
- **Agentic AI**: LangChain / LlamaIndex + Gemini or OpenAI agents  
- **Languages & Utilities**: SQL, Python, dbt (optional)  

**Project Type**: Advanced Data Engineering, ML & Agentic AI project focusing on modern data stack, enterprise BI, and intelligent automation  
**Outcome**:  
Delivered a comprehensive, production-ready customer intelligence platform with automated pipelines, sophisticated analytics, Looker BI dashboards, and Agentic AI capabilities. The system demonstrates advanced proficiency in cloud data platforms and AI-driven decision support.
