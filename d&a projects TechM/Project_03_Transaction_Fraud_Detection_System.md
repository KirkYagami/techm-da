### **Project 03**  
**Project Title**: Transaction Fraud Detection System  
**Project Description**:  
Designed and implemented a fraud detection pipeline that analyzes financial transactions in batch mode, identifies suspicious patterns using machine learning, and supports investigators with clear visual reports on GCP infrastructure.  

**Objective**:  
- Create Airflow DAGs for transaction data ingestion and preprocessing  
- Develop anomaly detection and classification models with BigQuery ML  
- Implement feature engineering for fraud-related signals  
- Build visualization dashboards highlighting fraud trends and risk scores  
- Establish automated daily prediction jobs  
- Include data validation and model performance monitoring  
- Document model explainability techniques  

**Dataset**:  
PaySim — Synthetic Financial Datasets for Fraud Detection. ~6.3 million simulated mobile money transactions with fraud labels, generated from real transaction patterns. Free, no application required.  
Link: https://www.kaggle.com/datasets/ealaxi/paysim1

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on anomaly detection and risk analytics  
**Outcome**:  
Delivered a functional fraud detection pipeline with strong predictive performance and supporting visualizations, highlighting skills in applied ML and cloud data workflows.
