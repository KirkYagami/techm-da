### **Project 13**  
**Project Title**: Real-time Fraud Detection & Investigation Intelligence System  
**Project Description**:  
Enhanced the fraud detection solution with Snowflake as the central data platform, rich Looker BI visualizations, and Agentic AI agents that assist investigators with automated case analysis and recommended actions.  

**Objective**:  
- Build robust Airflow + Snowflake data pipelines with streaming ingestion support  
- Train and deploy advanced fraud models using BigQuery ML  
- Develop comprehensive Looker BI dashboards for fraud pattern analysis and risk monitoring  
- Integrate Agentic AI for real-time alert investigation and recommendation generation  
- Implement model monitoring and feedback loops  
- Ensure auditability and compliance features  

**Dataset**:  
PaySim — Synthetic Financial Datasets for Fraud Detection. ~6.3 million simulated mobile money transactions with fraud labels, generated from real transaction patterns. Same dataset as Project 03; this version loads it into Snowflake and adds Looker BI dashboards plus an investigation agent. Free, no application required.  
Link: https://www.kaggle.com/datasets/ealaxi/paysim1

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud & Data Warehouse**: GCP, Snowflake  
- **ML Modeling**: BigQuery ML  
- **BI & Visualization**: Looker BI  
- **Agentic AI**: Autonomous investigation agents  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Advanced Data Engineering, ML & Agentic AI project focusing on risk and fraud analytics  
**Outcome**:  
Delivered a powerful fraud intelligence platform with enterprise BI, advanced modeling, and AI-assisted investigation capabilities.
