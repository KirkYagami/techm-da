### **Project 07**  
**Project Title**: Patient Readmission Risk Prediction System  
**Project Description**:  
Developed a healthcare analytics solution to predict patient readmission risks using clinical and demographic data processed through cloud-based pipelines and ML models.  

**Objective**:  
- Build secure Airflow pipelines for healthcare data processing  
- Train readmission risk models using BigQuery ML  
- Implement feature engineering from structured patient records  
- Create clinical dashboards for risk visualization  
- Enable scheduled risk scoring jobs  
- Ensure compliance-friendly documentation  

**Dataset**:  
Diabetes 130-US Hospitals for Years 1999-2008 (UCI Machine Learning Repository) — ~100,000 inpatient encounters with demographics, diagnoses, lab results, medications, and 30-day readmission label. Free, no application required, fully de-identified.  
Link: https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on healthcare analytics  
**Outcome**:  
Delivered a functional patient risk prediction system suitable for supporting clinical decision-making.
