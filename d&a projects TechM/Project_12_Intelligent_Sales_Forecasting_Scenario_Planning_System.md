### **Project 12**  
**Project Title**: Intelligent Sales Forecasting & Scenario Planning System  
**Project Description**:  
Built an advanced sales forecasting platform integrating Snowflake data warehouse, enterprise Looker BI dashboards, and Agentic AI agents capable of generating dynamic what-if scenarios and automated business recommendations.  

**Objective**:  
- Design hybrid Airflow pipelines ingesting data into Snowflake  
- Develop advanced time-series and ensemble models using BigQuery ML and Snowflake  
- Create executive-level interactive Looker BI dashboards with drill-down capabilities  
- Deploy Agentic AI agents for forecast interpretation, anomaly detection, and scenario simulation  
- Implement automated reporting and alert systems  
- Support multi-source data integration and governance  

**Dataset**:  
Walmart Recruiting - Store Sales Forecasting — weekly sales for 45 stores including holiday markdowns, fuel price, CPI, and unemployment as predictors. Same dataset as Project 02; this version routes the data through Snowflake and adds Looker BI dashboards plus an agent layer for scenario simulation. Free, no application required.  
Link: https://www.kaggle.com/datasets/aslanahmedov/walmart-sales-forecast

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud & Data Warehouse**: GCP, Snowflake  
- **ML Modeling**: BigQuery ML  
- **BI & Visualization**: Looker BI  
- **Agentic AI**: LangChain agents with reasoning capabilities  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Advanced Data Engineering, ML & Agentic AI project focusing on forecasting and intelligent business planning  
**Outcome**:  
Successfully implemented a sophisticated sales intelligence system featuring enterprise analytics, predictive modeling, and autonomous AI agents for strategic decision-making.
