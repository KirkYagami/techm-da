### **Project 14**  
**Project Title**: Hybrid Recommendation Engine with AI Personalization  
**Project Description**:  
Upgraded the recommendation system with Snowflake data management, advanced Looker BI analytics, and Agentic AI for dynamic personalization and marketing automation.  

**Objective**:  
- Orchestrate large-scale data processing pipelines into Snowflake using Airflow  
- Implement hybrid recommendation models combining BigQuery ML with additional techniques  
- Build detailed Looker BI dashboards for recommendation performance and customer segmentation  
- Deploy Agentic AI agents to generate personalized campaign ideas and content  
- Support online inference and feedback integration  
- Enable A/B testing and continuous optimization  

**Dataset**:  
MovieLens (ml-latest-small) — 100,836 ratings across 9,742 movies from 610 users, maintained directly by GroupLens Research (University of Minnesota). Same dataset as Project 04; this version stores it in Snowflake and adds Looker BI dashboards plus an LLM agent for generating personalized campaign content. Free, no account required.  
Link: https://grouplens.org/datasets/movielens/latest/ (or mirrored at https://www.kaggle.com/datasets/shubhammehta21/movie-lens-small-latest-dataset)

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud & Data Warehouse**: GCP, Snowflake  
- **ML Modeling**: BigQuery ML  
- **BI & Visualization**: Looker BI  
- **Agentic AI**: LangChain-based personalization agents  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Advanced Data Engineering, ML & Agentic AI project focusing on recommendation systems  
**Outcome**:  
Created a next-generation recommendation platform with intelligent automation and enterprise-grade analytics.
