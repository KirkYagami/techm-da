### **Project 02**  
**Project Title**: Sales Forecasting and Demand Planning System  
**Project Description**:  
Developed a robust sales forecasting solution that processes historical sales data through automated pipelines, generates accurate demand predictions using built-in ML capabilities, and presents forecasts via clear visualizations to support business planning decisions.  

**Objective**:  
- Build automated data ingestion and transformation workflows with Apache Airflow  
- Implement time-series forecasting models using BigQuery ML  
- Integrate data from multiple internal and external sources  
- Develop dashboards to visualize sales trends and forecast accuracy  
- Set up monitoring and alerting for pipeline failures  
- Enable periodic model retraining on fresh data  
- Produce exportable reports for stakeholder consumption  

**Dataset**:  
Walmart Recruiting - Store Sales Forecasting — weekly sales for 45 stores including holiday markdowns, fuel price, CPI, and unemployment as predictors. Free, no application required.  
Link: https://www.kaggle.com/datasets/aslanahmedov/walmart-sales-forecast

**Tools Used**:  
- **Orchestration**: Apache Airflow  
- **Cloud Platform**: Google Cloud Platform (GCP), BigQuery  
- **ML Modeling**: BigQuery ML  
- **Visualization**: Looker Studio / Data Visualization tools  
- **Languages & Utilities**: SQL, Python  

**Project Type**: Intermediate Data Engineering & ML project focusing on time-series forecasting and business intelligence  
**Outcome**:  
Successfully implemented an automated sales forecasting system that provides reliable predictions and visual insights, demonstrating end-to-end data pipeline and ML engineering skills.
